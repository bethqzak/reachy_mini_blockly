Reachy Blocks

Block coding for Reachy Mini. Snap blocks together in the WADSIH Block Console and watch the real robot move — no Python, no terminal.

What it does

  • 😊 Emotions — all 81 clips from the official library, with audio
  • 💃 Dances from the Pollen dances library
  • 🙂 Head & antenna control, by preset or exact angles
  • 🗣️ Text to speech through the robot's speaker
  • 📸 Camera snapshots your blocks can display
  • 👀 Face tracking — the head follows the nearest face
  • 🎛️ Settings page with a live preview and test buttons

Setup

  1. Install this app on your robot from the Reachy Mini dashboard.
  2. Press start.
  3. Open the Block Console in Chrome or Edge, on the same computer, and pick the Reachy Mini category.

Built for the Reachy Mini Lite: the console reaches the robot at localhost:8080, so the browser has to be on the same computer as the robot's daemon. No API keys needed. Apache-2.0 licensed.
