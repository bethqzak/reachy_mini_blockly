If the console can't find your robot

The Block Console reaches this bridge at http://localhost:8080, so the browser has to be on the same computer that is running the robot's daemon and this app. That is the normal setup for a Reachy Mini Lite plugged into your machine.

Use Chrome or Edge. Safari blocks plain-HTTP requests from an HTTPS page with no way to allow them, so the blocks will silently fail there.
